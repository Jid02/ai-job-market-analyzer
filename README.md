## 🌍 Problem Statement

The AI/ML job market is evolving rapidly, but **students and job seekers often lack clear insights** into:

* Which skills are actually in demand
* Which cities have the most opportunities
* What salary trends look like

Most platforms provide raw job listings — but not **actionable insights**.

---

## 💡 Solution

The **AI Job Market Analyzer** transforms raw job data into an **interactive intelligence dashboard** that helps users:

* Identify trending skills
* Analyze hiring hotspots
* Understand salary distributions
* Explore filtered job opportunities easily

---

## ✨ Key Features

✅ Interactive dashboard powered by Streamlit

✅ Filter jobs by city and skills

✅ Real-time data exploration

✅ Key metrics:

* Total Jobs
* Top Skills
* Top Cities
* Average Salary

✅ Download filtered dataset as CSV

## ⚙️ Installation & Setup

```bash
# Clone repository
git clone https://github.com/Jid02/ai-job-market-analyzer.git

# Move into folder
cd ai-job-market-analyzer

# Install dependencies
pip install -r requirements.txt

# Run application
streamlit run app.py
```
